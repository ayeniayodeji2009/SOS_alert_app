POSTGRE Controls
> start postgre server via CDM as admin - "C:\Program Files\PostgreSQL\17\bin\pg_ctl.exe" -D "C:\Program Files\PostgreSQL\17\data" start
> stop postgre server via CDM as admin -  "C:\Program Files\PostgreSQL\17\bin\pg_ctl.exe" -D "C:\Program Files\PostgreSQL\17\data" stop
> Check if postgre server is running - tasklist | findstr postgres
> location to delete .pid file  -  C:\Program Files\PostgreSQL\17\data

> 1. Kill duplicate processes if reconnection of backend and database server are not working

cmd
